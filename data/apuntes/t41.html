1. Lenguajes de interrogación

  • Lenguajes procedimentales (dicen cómo obtener los datos, como el álgebra relacional) y declarativos (dicen qué datos se quieren, como el cálculo relacional y SQL).
  • SQL (Structured Query Language), originado en el System R de IBM (SEQUEL). Estándar ANSI en 1986 e ISO/IEC 9075; versiones SQL-86, SQL-89, SQL-92, SQL:1999 (consultas recursivas, triggers), SQL:2003 (funciones de ventana, XML), SQL:2008, SQL:2011 (datos temporales), SQL:2016 (JSON), SQL:2023 (grafos con SQL/PGQ, JSON ampliado).
  • Cada producto añade extensiones procedimentales: PL/SQL (Oracle), T-SQL (SQL Server), PL/pgSQL (PostgreSQL).
  • Otros lenguajes: QBE, consultas de bases NoSQL (MQL de MongoDB, Cypher para grafos), SPARQL (RDF).

2. Sublenguajes de SQL

TipoSentencias
DDL (definición)CREATE, ALTER, DROP, TRUNCATE (tablas, vistas, índices, esquemas)
DML (manipulación)SELECT, INSERT, UPDATE, DELETE, MERGE
DCL (control)GRANT, REVOKE
TCL (transacciones)COMMIT, ROLLBACK, SAVEPOINT, SET TRANSACTION

Restricciones en CREATE TABLE: PRIMARY KEY, FOREIGN KEY ... REFERENCES, UNIQUE, NOT NULL, CHECK, DEFAULT.

3. La sentencia SELECT

SELECT [DISTINCT] columnas | expresiones | funciones de agregado
FROM tabla [JOIN otra ON condición]
WHERE condición sobre filas
GROUP BY columnas
HAVING condición sobre grupos
ORDER BY columnas [ASC|DESC]
FETCH FIRST n ROWS ONLY;   -- (LIMIT en MySQL/PostgreSQL, TOP en SQL Server)
  • Orden lógico de evaluación: FROM → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → límite. Por eso en WHERE no se pueden usar alias del SELECT ni funciones de agregado.
  • Funciones de agregado: COUNT, SUM, AVG, MIN, MAX. COUNT(*) cuenta filas; COUNT(columna) ignora los NULL.
  • Operadores: =, <>, BETWEEN, IN, LIKE ('%' cualquier cadena, '_' un carácter), IS NULL (nunca "= NULL"), EXISTS, ANY/SOME, ALL.
  • Joins: INNER JOIN (solo coincidencias), LEFT/RIGHT [OUTER] JOIN (todas las filas de un lado y NULL en el otro), FULL OUTER JOIN, CROSS JOIN (producto cartesiano), NATURAL JOIN, autojoin.
  • Subconsultas: escalares, en IN/EXISTS, correlacionadas (se evalúan por cada fila de la consulta externa), en FROM (tablas derivadas).
  • Operadores de conjuntos: UNION (sin duplicados), UNION ALL (con duplicados), INTERSECT, EXCEPT (MINUS en Oracle).
  • CTE (WITH) y consultas recursivas (WITH RECURSIVE).
  • Funciones de ventana: ROW_NUMBER(), RANK(), DENSE_RANK(), SUM() OVER (PARTITION BY ... ORDER BY ...).
  • CASE, COALESCE, NULLIF, CAST; lógica de tres valores con NULL.

4. Otros elementos

  • Vistas (CREATE VIEW): consultas guardadas; sirven para simplificar y para seguridad. Vistas materializadas.
  • Transacciones: COMMIT confirma, ROLLBACK deshace; SAVEPOINT para puntos intermedios.
  • Privilegios: GRANT SELECT, INSERT ON tabla TO usuario [WITH GRANT OPTION]; REVOKE.
  • Seguridad: consultas parametrizadas (prepared statements) para evitar la inyección SQL.
  • Diferencias: DELETE borra filas (con WHERE, se puede deshacer); TRUNCATE vacía la tabla (DDL, rápido); DROP elimina la tabla.

Claves para el test

  • WHERE filtra filas; HAVING filtra grupos.
  • Comparar con NULL: IS NULL.
  • UNION quita duplicados; UNION ALL no.
  • LEFT JOIN devuelve todas las filas de la tabla de la izquierda.
  • GRANT y REVOKE son DCL; COMMIT y ROLLBACK, TCL.
