1. HTML5: conceptos generales

  • HTML (HyperText Markup Language) describe la estructura y el significado del contenido web. HTML5 es hoy el HTML Living Standard que mantiene el WHATWG (el W3C lo respalda desde 2019).
  • Novedades de HTML5: elementos semánticos, nuevos tipos de input y validación nativa, audio y vídeo sin plugins, canvas y SVG integrado, APIs (almacenamiento local, geolocalización, arrastrar y soltar, Web Workers, WebSockets, historial).
  • HTML define el contenido; CSS la presentación; JavaScript el comportamiento.

2. Estructura y sintaxis

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Título</title>
    <link rel="stylesheet" href="estilos.css">
  </head>
  <body> ... </body>
</html>
  • Elementos con etiqueta de apertura, contenido y cierre; elementos vacíos (br, img, input, meta). Atributos globales: id, class, style, lang, title, hidden, data-*.
  • Semánticos: header, nav, main, article, section, aside, footer, figure/figcaption, time. Mejoran la accesibilidad y el posicionamiento.
  • Elementos de bloque (div, p, h1-h6, ul, table) y en línea (span, a, strong, em, img).

3. Formularios

  • <form action="url" method="get|post">: GET envía los datos en la URL (búsquedas); POST en el cuerpo de la petición (datos sensibles o voluminosos). enctype="multipart/form-data" para subir ficheros.
  • Controles: input (types text, password, email, url, tel, number, range, date, time, datetime-local, color, checkbox, radio, file, hidden, search, submit, reset), textarea, select con option y optgroup, button, datalist, output, fieldset y legend.
  • label asociado al control con for/id (imprescindible para la accesibilidad).
  • Atributos: name, value, placeholder, required, pattern (expresión regular), min, max, step, minlength, maxlength, readonly, disabled, autocomplete, autofocus, multiple.
  • Validación nativa del navegador con la Constraint Validation API (pseudoclases :valid e :invalid). La validación del cliente no sustituye a la del servidor.

4. Elementos interactivos y eventos

  • Elementos interactivos: details/summary (desplegable), dialog (ventana modal), audio y video con controls.
  • Eventos: acciones que ocurren en la página y a las que JavaScript puede responder. De ratón (click, dblclick, mouseover), teclado (keydown, keyup), formulario (submit, input, change, focus, blur), ventana y documento (load, DOMContentLoaded, resize, scroll), táctiles y de arrastre.
  • Gestión: elemento.addEventListener('click', funcion) (recomendado) o atributos on* (onclick). El objeto event y event.preventDefault() (por ejemplo, para validar antes de enviar).
  • Propagación: fase de captura y de burbuja (bubbling); stopPropagation(); delegación de eventos.
  • DOM: representación en árbol del documento que JavaScript lee y modifica.

5. CSS3: conceptos y sintaxis

  • CSS (Cascading Style Sheets, W3C) separa la presentación del contenido. CSS3 se divide en módulos (selectores, colores, fondos y bordes, flexbox, grid, media queries, transiciones, animaciones, transformaciones).
  • Formas de aplicarlo: hoja externa (link), interna (style en el head) y en línea (atributo style).
  • Sintaxis: selector { propiedad: valor; }. Comentarios /* */. @media, @font-face, @import, @keyframes.
  • Cascada: decide qué regla gana según origen e importancia (!important), especificidad y orden de aparición. Herencia: algunas propiedades (color, font) pasan a los hijos.
  • Especificidad (de mayor a menor): estilos en línea → id → clases, atributos y pseudoclases → elementos y pseudoelementos. Se calcula como (a, b, c).
  • Unidades: absolutas (px) y relativas (%, em, rem, vw, vh). Colores: nombre, hexadecimal, rgb(), hsl().

7. El modelo de caja (Box Model)

  • Cada elemento es una caja formada, de dentro afuera, por contenido (width/height), relleno (padding), borde (border) y margen (margin).
  • Con box-sizing: content-box (por defecto) el ancho total = width + padding + border (+ margin para el espacio ocupado). Con box-sizing: border-box el width ya incluye padding y borde.
  • Los márgenes verticales adyacentes de elementos de bloque se colapsan (se toma el mayor).
  • display: block, inline, inline-block, none, flex (una dimensión: justify-content, align-items) y grid (dos dimensiones: grid-template-columns). position: static, relative, absolute, fixed, sticky.
  • Diseño adaptable (responsive): media queries (@media (max-width: 600px)), unidades relativas, imágenes flexibles y enfoque mobile first.

Claves para el test

  • Box model: contenido, padding, border, margin.
  • border-box incluye padding y borde en el width.
  • Especificidad: en línea > id > clase/atributo/pseudoclase > elemento.
  • GET envía los datos en la URL; POST en el cuerpo.
  • required y pattern = validación nativa; label con for para accesibilidad.
