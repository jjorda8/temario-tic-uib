1. Conceptos básicos

  • GNU/Linux: núcleo Linux más herramientas GNU. Distribuciones: familia Debian (Debian, Ubuntu; paquetes .deb con apt/dpkg) y familia Red Hat (RHEL, Rocky, AlmaLinux, Fedora; .rpm con dnf/rpm).
  • Arranque: firmware (BIOS/UEFI) → cargador (GRUB2) → núcleo → systemd (PID 1) → unidades y targets. Gestión de servicios con systemctl start|stop|enable|status; registros con journalctl.
  • Jerarquía de directorios (FHS): /etc (configuración), /var (datos variables y logs en /var/log), /home (usuarios), /root, /usr (programas), /bin y /sbin, /tmp, /dev (dispositivos), /proc y /sys (virtuales del núcleo), /boot, /opt, /mnt y /media.
  • Shell (bash): redirecciones (>, >>, 2>, |), variables, scripts. Comandos básicos: ls, cd, cp, mv, rm, find, grep, ps, top, kill, df, du, free, mount, tar, ssh, scp, ip, ss.
  • Procesos y prioridades (nice), tareas programadas (cron, timers de systemd), gestión de discos (particiones, LVM, sistemas de ficheros ext4, XFS), montaje en /etc/fstab.

2. Usuarios y grupos

  • /etc/passwd: usuario, x, UID, GID principal, comentario, directorio personal y shell. Root tiene UID 0; los usuarios del sistema, UID bajos.
  • /etc/shadow: contraseñas cifradas (hash) y caducidad; solo legible por root. /etc/group y /etc/gshadow para grupos.
  • Comandos: useradd/adduser, usermod (-aG para añadir a grupos), userdel, passwd, chage (caducidad), groupadd, id, su.
  • sudo: ejecutar como otro usuario según /etc/sudoers (editar con visudo); grupo sudo o wheel. Mejor que compartir la contraseña de root.
  • PAM: módulos de autenticación configurables (políticas de contraseña, bloqueo, MFA). Integración con LDAP o Active Directory (SSSD, realmd).

3. Permisos

  • Tres tipos de permiso (r lectura = 4, w escritura = 2, x ejecución = 1) para usuario propietario, grupo y otros. Ejemplo: 750 = rwxr-x---; 644 = rw-r--r--.
  • En directorios: r = listar, w = crear y borrar ficheros, x = entrar.
  • Comandos: chmod (simbólico u octal), chown (propietario y grupo), chgrp.
  • umask: permisos que se quitan a los ficheros nuevos (022 → ficheros 644 y directorios 755).
  • Permisos especiales: SUID (4000, se ejecuta con los permisos del propietario, como passwd), SGID (2000, con el grupo; en directorios, los ficheros heredan el grupo) y sticky bit (1000, en /tmp solo el propietario puede borrar sus ficheros).
  • ACL para permisos más finos: getfacl, setfacl.
  • Atributos especiales (chattr +i hace un fichero inmutable).

4. Seguridad

  • Actualizaciones periódicas (apt, dnf; actualizaciones automáticas de seguridad).
  • SSH seguro: autenticación por clave pública, desactivar el acceso de root y las contraseñas (PermitRootLogin no, PasswordAuthentication no), Fail2ban frente a fuerza bruta.
  • Cortafuegos: nftables (sucesor de iptables), firewalld (zonas, en Red Hat), ufw (en Ubuntu).
  • Control de acceso obligatorio (MAC): SELinux (Red Hat; modos enforcing, permissive, disabled) y AppArmor (Debian/Ubuntu, perfiles por programa).
  • Auditoría con auditd, registros en /var/log y journald, envío a un SIEM; integridad con AIDE.
  • Mínimos servicios instalados, mínimo privilegio, particiones separadas con opciones noexec y nosuid, cifrado de disco (LUKS).
  • Guías CCN-STIC de bastionado y benchmarks CIS.

Claves para el test

  • SUID 4000, SGID 2000, sticky 1000 (el de /tmp).
